    Mensagem padrão para o vendedor

    Campos que o app preenche sozinho: {carro} {ano} {preco} {km} {link} {meu_carro}. Em cada anúncio você ainda pode editar antes de enviar.

    Pesquisa automática

    A pesquisa roda sozinha por volta das 6h e das 13h. Quando você muda o filtro, o app envia o filtro e uma pesquisa extra roda na hora seguinte. O token do GitHub (com permissão Contents e Issues: Read and write no repositório carmonitor) é o que permite esse envio automático.

    Seus dados

    Tudo fica salvo só neste aparelho. Faça cópias de segurança de vez em quando.

    Fichas por versão

    Valem só para a mesma marca, modelo, versão e ano-modelo. Item “opcional” nunca confirma. Toda ficha exige a fonte.
